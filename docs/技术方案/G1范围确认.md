## 3. 确认的效力与失效条件

1. **本单确认的是范围，不是实现细节。** §2 每项的具体验收标准以本科版实施方案.md 对应行号为准；本单不复制、不改写验收标准。
2. **§3 的「若时间富余再补的条件」是硬门槛**，不是愿望清单：条件不满足即永远不做，不因为「看起来还有时间」而回头补。
3. **本单不覆盖排期与关卡。** 四个硬关卡（G3 人工标注 / G5 实验图表化 / G8 系统骨架 / G9 联调与可复现性）的不达标降级动作写在本科版实施方案.md §6 的关卡表里，与本单分开执行。
4. **有异议怎么办**：任何一条勾「有异议」，该条即视为**未确认**，须在下方「异议记录」写明诉求与处理结论；未处理完的异议不阻塞其余条目的确认。
5. **签字后的变更**：范围增删须重新走一次本单，并在下方变更记录追加一行；**不得靠口头或聊天记录改范围**。
6. **「第二标注者」不属本单范围**：G1 关卡还包含确认第二标注者的人选与 TA 时间（见本科版实施方案.md:223），该确认在工单 #4 内单独记录，不并入本单。
