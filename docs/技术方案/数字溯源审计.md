## 1. 结论

**附录 D 与实测产物的一致率为 90 / 104（86.5%）。** 分母 104 条原子声明 = 附录 D 主表 45 条 + 附录 D「标准化实验实测」小节 59 条（按表内实际行数计）。分子 90 条判定为 `一致` 或 `已被实测修正`。**不一致 0 条**，**无出处 14 条**。

原先判为无出处的整篇级 AUC 0.936、失败归一化 0.512 / 0.448 / 0.384、方向 C 的 σ 0.1286 与组内余弦区间 0.982–0.985，本次已分别由 `granularity.csv`、`results_auc.csv`、`granularity_dup.csv` 补齐机读出处并改判为 `一致`，详见 §2.1 与 §5.1。

正文各节的原子声明另计 **150 条**：`一致` 102 条、`已被实测修正（文档已自行声明）` 1 条、`不一致` **1 条**、`【无出处】` 44 条，另有 3 条「一表两判」的混合行（同一行内既有可核验值又有无出处值，如「前两项 `一致`，后两项 `【无出处】`」），单列计数。正文的无出处比例显著高于附录 D，原因集中在：HDBSCAN 簇数与耗时（95 / 88 / 两次运行 1.18·1.07 与 1.03·1.28 秒）、人工标注类承诺（Cohen's Kappa、md5 一致性）、banking77 语料规模、模型参数量与落盘体积。
