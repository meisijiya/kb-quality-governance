## 0. 执行摘要（一句话结论）

**四种打分里 S1（分位数排名）和 S2（全局 z-score）在数学上不可能超过 0.968 —— 它们与绝对阈值严格单调等价，Spearman ρ = −1.000000，AUC 恒等于 0.968；唯一打破 0.968 的 S3（领域内 z-score）与 S5（双参考系均值）在 alpha 场景拿到 AUC = 1.0000，但它们在真实英文语料 banking77 上分别崩到 0.4344 / 0.7516，低于绝对阈值的 0.9538 —— 两个 embedding 模型上都是。**

一句话：**这条路走不通 —— 不是因为方向错，而是因为「标准化」这个动作本身分成了两半：只换刻度（S1/S2/S6）数学上不改变排序，一点信息都加不了；真去改变排序（S3/S4/S5）就等于把跨域比较的信息扔掉，在真实语料上必然反噬。**

补充一条同样重要的正面结论：**「阈值可迁移性」这个指标本身可以被单独优化成假象。** §8 方向 A 的跨场景阈值极差只有 0.0018（比基线 0.0264 稳一个数量级），但它的 AUC 是 0.096–0.317 —— **比随机还差**。可迁移与有效是两个独立性质，必须同时报告。

## 1. 先说清楚一个数学事实（这是全报告的地基）

AUC 是一个**纯排序指标**（Mann-Whitney U 统计量）。它只依赖工单之间的**相对次序**，完全不依赖数值的绝对刻度。

因此：

> **任何对 cover 施加的严格单调递增变换 g，都满足 AUC(g(cover)) ≡ AUC(cover)。**

| 打分 | 定义 | 与 cover 的 Spearman ρ | alpha AUC |
|---|---|---|---|
| ABS 绝对阈值 | `−cover` | −1.000000 | 0.9680 |
| S1 分位数排名 | `1 − pct_rank(cover)` | **−1.000000** | **0.9680** |
| S2 全局 z-score | `−(cover−μ)/σ` | **−1.000000** | **0.9680** |
| S6 去极值 z | `−z(clip(cover))` | −0.999817 | 0.9680 |
| S3 领域内 z | `−z_within_domain(cover)` | −0.893715 | 1.0000 |
| S4 双参考系(域) | `−max(z_g, z_w)` | −0.972351 | 0.9840 |
| S5 双参考系均值 | `−(z_g + z_w)/2` | −0.971441 | 1.0000 |
| S4b 双参考系(意图) | `−max(z_g, z_w_intent)` | −0.814022 | 0.7520 |

（完整表见 `mechanism.csv`）

**S1/S2 的 ρ 精确等于 −1.000000，意味着它们连一个工单对的相对次序都没有交换。** 所以「S1/S2 能不能打败 0.968」这个问题本身是无意义的 —— 答案在跑实验之前就已经是「不能，且任何数据集上都永远不会能」。

这解释了一个初看很反直觉的现象：**S1/S2 在 alpha 场景一个百分点都没赢，但它们在阈值迁移上的表现和绝对阈值一模一样差**（见 §4）。因为它们的排序完全相同，阈值失效的原因（排序没变）也一样。

S6 的 ρ = −0.999817，不是精确的 −1 —— 因为裁剪把两端极值压成了并列值，打破了 1 个工单对的次序。这带来 0 个 AUC 变化（0.9680），说明那一对恰好都是负类。

**能改变排序的只有「分组标准化」类（S3/S4/S5），因为组内 z-score 是分段的不同仿射变换，整体不再是单一仿射变换。**

## 2. 四种打分的数学定义与几何直觉

### S1 分位数排名

$$s_1(i) = 1 - \frac{\#\{j : c_j < c_i\}}{\text{半}} \quad\text{（并列取平均秩）}$$

几何直觉：把这条工单放到本批语料的相似度数轴上，看它排在第几个百分位。

```
  cover 数轴（alpha: min=0.563  mean=0.689  max=0.829）
  0.563        0.689                    0.829
   |------------|------------------------|
   0%          50%                      100%     pct_rank
   ↑ 缺口工单都挤在这一侧
  s1 = 1 - pct  →  缺口工单 s1 接近 1
```

优点：完全免疫语料整体偏移（μ 变了 pct 不变）。
缺点：ρ=−1，**零信息增益**。而且它把语料的**形状信息**（本语料相似度分布有多宽）完全丢弃了 —— 一个 sd=0.05 的语料和一个 sd=0.30 的语料，S1 给出的分数一模一样。

### S2 标准化 z-score

$$s_2(i) = -\frac{c_i - \mu}{\sigma},\qquad \mu=\text{mean}(c),\ \sigma=\text{std}(c)\ (ddof=1)$$

几何直觉：这条工单距离语料中心有几个标准差。

```
   缺口意图            全部意图              非缺口意图
     簇                   |                      簇
   -2.5σ  -1.5σ   -1σ  μ  +1σ  +2σ  +2.5σ
     ▼     ▼             |              ▼     ▼
  s2 大               s2 ≈ 0        s2 小
```

比 S1 多保留了「离群多远」的信息（σ 的尺度），但仍然是全局仿射变换，ρ 仍是 −1，**AUC 依旧恒等**。

### S3 领域内标准化

$$s_3(i) = -\frac{c_i - \mu_{d(i)}}{\sigma_{d(i)}},\qquad d(i)=\text{工单 } i \text{ 的业务域}$$

几何直觉：先承认「财务类工单天生比信息安全类工单更容易匹配上」这个业务事实，在每个域内部各建一把尺子，再跨域比较这把尺子上的位置。

```
   全局尺子（错）：财务域均值 0.78   信息安全域均值 0.65
                    └──┬──┘         └────┬────┘
   一个「真的没覆盖」的财务工单可能落在 0.60，
   一个「其实覆盖得很好」的信息安全工单可能落在 0.66，
   全局比较会判错其中一个。

   分域尺子（对）：财务域内 z = -2.4   信息安全域内 z = +0.1
                       ↓ 判为缺口          ↓ 判为已覆盖
```

前提：业务域标签必须可得，且域内分布要近似单峰。

### S4 / S5 双参考系

$$s_4(i) = -\max\bigl(z_{\text{global}}(c_i),\ z_{\text{within}}(c_i)\bigr)\qquad s_5(i) = -\frac{z_{\text{global}}(c_i) + z_{\text{within}}(c_i)}{2}$$

几何直觉：同时问两个问题 ——「相对**整体**差吗」和「相对**同类**也差吗」。只有**两个参照系都判它差**，才认定为缺口（这就是取 max 再取负，即 min 语义）。S5 用算术平均，是一个更软的折中。

```
        z_global=  -1.2σ  (整体里算差)
        z_within=  +0.3σ  (同类里不算差)   →  max = -1.2  →  s4 = 1.2   （还是判缺口，因为 s4 只看最悲观的）

        z_global=  -0.1σ  (整体里不算差)
        z_within=  -2.6σ  (同类里很差)     →  max = -0.1  →  s4 = 0.1   （判已覆盖）
```

注意 s4 的语义是「**只要有一个参照系说它不差，就不算缺口**」—— 这在 alpha 场景是有利的（保守，减少误报），代价是召回。

## 4. 实验 2：阈值可迁移性（核心实验）

### 4.1 五个场景的定义与 ground truth

| 场景 | 文档数 | cover min / mean / max | sd | ground truth 缺口意图数 | ground truth 如何确定 |
|---|---|---|---|---|---|
| α 完整语料 | 300 | 0.5629 / 0.6891 / 0.8294 | 0.0529 | 5 | 原型 `ground_truth.json` |
| β 缩小语料 | 75 | 0.5063 / 0.6565 / 0.8294 | 0.0500 | 7 | 5 个原有 + 抽签抽空了全部文档的 2 个（差旅费报销、考勤异常处理） |
| γ 域偏移 | 180 | 0.5628 / 0.6704 / 0.8038 | 0.0508 | 15 | 5 个原有 + 保留 4 域后失去全部文档的 10 个 |
| γ-X 极端域偏移 | 48 | 0.5405 / 0.6382 / 0.7649 | 0.0415 | 26 | 5 个原有 + 只剩财务域后失去全部文档的 21 个 |
| δ 文档翻倍 | 600 | 0.5629 / 0.6892 / 0.8294 | 0.0528 | 5 | 同 α（副本不新增语义覆盖） |

**关于 β/γ/γ-X 重新定义 ground truth 的方法（任务书要求说明）：**

原则是「**知识库里一篇文档都没有的意图，就算知识缺口**」—— 与原型的埋设规则一致（原型的 5 个缺口意图就是「300 篇文档里 0 篇覆盖」）。具体地：

1. 用 `docs.csv` 的 `title` 反查每篇文档归属哪个意图（`关于{intent}{aspect}的说明`），得到 doc→intent 映射，300 篇全部匹配成功、无歧义（`explore.py` 实测）。
2. 每个场景选定一个文档子集，统计哪些意图**还剩至少 1 篇文档**（alive）。
3. 新 ground truth = `{ i : alive 中无 i } ∪ {原型 5 个缺口意图}`。

这个定义的可辩护性在于：它不依赖任何模型输出，只依赖「文档是否归属于该意图」这一可人工核验的事实。β/γ 下 alive 意图的 cover 确实显著更高（见 `results_auc.csv` 中 ABS 的 AUC 0.8075/0.9022，均 > 0.5，说明定义与覆盖度信号一致）。

**δ 场景的诚实说明**：文档翻倍 + 同义扰动后 cover 分布几乎没有变化（mean 0.6891→0.6892，sd 0.0529→0.0528），所以 δ 的所有 AUC 与 α 完全相同，衰减恒为 0。**这个场景没有产生信息，如实记录。** 原因是 max-cosine 只取最大段落相似度，加冗余副本不会抬高最大值（原型 §5.3 已实测重复件相似度 0.982–0.985，但那是同源文档对；对一条**未被覆盖**的工单，加再多同域文档它也还是没被覆盖）。

**这张表是本实验最重要的结果，而且它与直觉相反：**

绝对余弦阈值在**同一个模型、同一种语言**内换语料，所需阈值的极差只有 **0.0264**（−0.6657 ~ −0.6897）。它其实**相当稳**。
反倒是「自适应」的 S2/S3/S4/S5，所需阈值横跨 1.4 ~ 2.0 个单位，**极不稳定**。

原因：绝对阈值只依赖 cover 的绝对刻度，而 BGE-small-zh 的刻度是由模型权重决定的，**换语料不动它**；而 z-score 的刻度是「本批语料的 μ/σ」，语料一变刻度就跟着变，于是**同一个 z 阈值在不同语料里指向了不同的绝对相似度**。

**所以「用自适应标准化来提高可迁移性」这个直觉，在数据上是错的。** 自适应把「模型刻度不变」这个真正的稳定来源给扔掉了。

| 中文合成语料 α | cover ≤ 0.6463 | `bge-small-zh-v1.5` | 反向：cover ≥ 0.6463 → 缺口 | **77 / 77** | 0.1948 | 1.0000 | **0.3261** | 0.6207 |

中文语料上 0.6463 这个「最优点」，搬到 banking77 后**正着过不去、反着全中**：正向判定一个缺口都检不出（0 / 77，P=0，R=0，F1 = 0），反向判定把全部 77 个意图都判成缺口（P 0.1948、R 1.0000、F1 0.3261）。两个方向都不可用。

这就是任务书里「绝对阈值不可迁移」最赤裸的证据 —— 但要注意，**失效的原因是模型/语言换了（BGE 的英文相似度整体抬高到 0.60–0.99），不是语料规模变了**。**换用完全匹配的英文模型 `bge-small-en-v1.5` 后，最优阈值变成 0.8495，与中文的 0.6463 相差 0.20 —— 印证了「刻度由模型决定」。**

这给出了一个更准确的论断：**绝对阈值锚定的是「模型 × 语言」的刻度。模型和语言不变时它相当稳（§4.3 极差 0.0264）；模型或语言一变，它全线崩溃。**

## 7. 诚实评价：这条路什么时候会失效、依赖什么假设

### 7.1 整体判断

**这条路（用语料基线标准化替代绝对阈值）走不通。** 三条独立证据：

1. **信息论层面**：S1/S2/S6 与 cover 严格单调等价（AUC 恒等），标准化不改变排序就不改变任何排序类指标。它们唯一改变的是「阈值落在数轴哪里」，而这恰恰是它们做得更差的地方（§4.3 极差 0.54–2.03 vs ABS 的 0.026）。
2. **真实数据层面**：S3/S5 在 banking77 上从 1.0000 掉到 0.4946/0.6387，低于原始绝对阈值 0.7925（§6.3）。
3. **迁移性层面**：S3 的跨场景 AUC 衰减（平均 0.2892）是 ABS（0.0936）的 3.1 倍（§4.2）。

### 7.2 前提假设与失效条件

对**被否决的 S3/S4/S5**（分组标准化）而言：

| 前提假设 | 实测是否成立 | 失效后果 |
|---|---|---|
| 业务域标签可得且正确 | 中文合成语料成立（人工构造），**真实企业语料通常不成立** | 无法分组，方案退化为 S2 |
| 域内 cover 分布近似单峰、且各域形状可比 | **banking77 上不成立**（英文 query 长度方差大，域是我用相似度硬凑的 4 类） | z-score 失去可比性 → AUC 0.4946 |
| 缺口在「业务域」这个粒度上是同质的 | **不成立**。γ-X 场景里 26 个缺口意图中有 21 个是「因域被删而失去覆盖」，它们的域内参照系整个塌掉了 | γ-X 下 S3 = 0.6442 |
| 组内样本量足够估计 μ/σ | 成立（最小 39 条） | 小组时 z 噪声大 |

对**绝对阈值本身**而言，失效条件是明确且可预测的：

- **模型或语言一变就崩**（§4.5：中文 0.6463 搬到英文 → 77/77 全判为缺口，P=0.195）；
- 同一模型同语言内反而相当稳（§4.3 极差仅 0.0264）。

所以真正该写进论文的结论是：**「绝对阈值锚定的是模型+语言刻度；刻度不变时它是稳的，刻度一变它全线崩溃」**，而不是「绝对阈值不可用」。

### 7.3 我这套实验本身的局限（必须写进论文的诚实提示）

1. **AUC=1.0000 有数据规整的成分**。原型 300 篇文档是按 25 个意图 × 12 篇等距生成的，同一意图的 12 篇文档来自同一个模板 PROFILES，域内相似度天然偏高。S3 在这种「域内同质」的构造上拿 1.0000 并不奇怪。真实语料不会有这种结构 —— banking77 两个模型分别给出 0.4344 / 0.4946 就是证据。
2. **域标签的获取成本被我免费了**。S3/S4/S5 都假设业务域已知。中文合成语料的域是数据构造时自带的（`gen_data.COVERED_INTENTS`），5 个缺口意图的域是我用工单向量对各域文档的相似度**反推**的（`explore.py` 实测，top-1 与 top-2 的相似度差距只有 0.005~0.036，`explore.py` 有完整输出）；banking77 的域则是我用 KB 文档相似度硬凑的 4 类，**基本是噪声**。**用 HDBSCAN 聚类结果冒充业务域的实验没有做，这是本实验最大的缺口**，也是 §6.5 中 S3 失效的一个可能解释（如果 S3 换成 HDBSCAN 簇作为组，表现可能不同）。
3. **β/γ 的 ground truth 是「文档是否归属该意图」的推断，不是人工标注**。虽然这个推断可核验（300 篇标题全部无歧义匹配），但它假定「一篇文档只服务一个意图」，而原型数据确实如此构造。真实企业知识库不会有这个性质。
4. **只测了 5 个场景、2 个 embedding 模型、1 个真实语料**。样本量不足以支撑「标准化路线整体不可行」的强论断，只能支撑「在本次实测范围内，标准化路线没有超过绝对阈值」。banking77 只有一个领域（银行），中文语料是合成的。
5. **δ 场景无效**（分布几乎没变），如 §4.1 所述。
6. **banking77 子场景的正负比例失衡**（15/77 → 57/77），使 §6.6 那两栏的 AUC 统计效力很弱，不应据此判断方案优劣（已在 §6.6 标注）。
7. **§8 方向 A/B 的判决受本语料特性影响**。方向 B（文档流行度先验）在本语料上必然吃亏，因为 49/300 篇是重复件；方向 A 的证伪结论更普适（机理与语料无关）。
8. **未测「换更大的 embedding 模型」**。bge-base-zh（768 维）的绝对刻度与 bge-small-zh 不同，阈值能否迁移没验证。

## 8. 后续方向 —— 已实测，不是「建议」

我在写初稿时提出了 3 个方向，写完立刻用 `directions.py` 实测了一遍。**其中一个被我自己的实验证伪了，如实记录。**

失败分析指向的共同病因：**所有方案都只用 cover 这一个标量**。cover 把「跟谁像」这个最有信息的维度压成了一个数。要加信息，只能引入第二个量。以下方向 A/B/C 都保留绝对余弦的刻度稳定性（不做全语料标准化），因此不会重蹈 §4.3 的覆辙。

---

### 方向 A：「top-k 段落分数的分布形状」 —— ❌ **已被我自己证伪**

**初稿假设**：`cover = max_j` 是极值统计量，对语料规模敏感。改用「同一工单内部」的形状量：

$$A1(i) = -\frac{\mu_{\text{top-5}}(i) - \min_j \cos(t_i,p_j)}{\max_j\cos(t_i,p_j) - \min_j\cos(t_i,p_j)}$$

直觉：有明确对应文档时，最优段落会**孤立突出**（top-5 均值远低于 max）；无对应文档时所有段落「沾点边」同分（top-5 均值接近 max）。

**实测结果（`results_directions.csv`，4 场景）：**

| 变体 | α | β | γ | γ-X | 跨场景阈值极差 |
|---|---|---|---|---|---|
| **ABS −max（基线）** | **0.9680** | **0.8075** | **0.9022** | **0.9135** | 0.0264 |
| A1 (top5−mean)/(max−min) | 0.0960 | 0.1615 | 0.1400 | 0.3173 | 0.0051 |
| A2 (max−top5)/max | 0.1120 | 0.1491 | 0.1444 | 0.2788 | 0.0018 |
| A3 (max−top5)/span | 0.0960 | 0.1615 | 0.1400 | 0.3173 | 0.0051 |
| A4 top5 − max | 0.9200 | 0.8509 | 0.8644 | 0.7981 | 0.0218 |

**判决：证伪。** A1/A2/A3 的 AUC 是 **0.096–0.317**，即**比随机还差得多**（AUC < 0.5 意味着方向完全反了）。A4（`top5 − max`，唯一方向没搞反的）AUC 0.920，**仍然低于基线 0.9680**。

**为什么失败（机理）**：`max − top5 均值` 度量的是「最相关段落的孤立程度」，而它与缺口**负相关甚至反相关** —— 一个没被覆盖的工单，其 top-1 段落往往是「碰巧沾边但很独特」的（因为全库都沾边，最高的那个反而最特殊）；一个被良好覆盖的工单，top-1 与 top-5 都来自同一文档的邻近段落，差距反而小。**形状量在这里测的是「检索有多独特」，不是「有没有覆盖」。** 这与原型 RESULT.md §2.3 已记录的 `max − top5 均值 = 0.512`（近随机）方向一致，我只是把它换了几种归一化后重测，全部落进 0.10–0.32 区间。

值得注意的是：A2 的跨场景阈值极差只有 **0.0018**，比 ABS 的 0.0264 还小一个数量级 —— **形状量的刻度稳定性确实极好，但它的 AUC 太差，稳定地稳定在错的方向上。**

**这个负结果本身有价值**：它说明「跨场景可迁移」和「AUC 高」是两个独立的性质，本任务要求的核心指标（可迁移性）单独优化是可能骗人的。

---

### 方向 B：检索侧双向中心化（减去文档流行度先验） —— ❌ **实测无效**

**初稿假设**：不需要业务域标签，让知识库自己提供基准 —— 「这条工单像某篇文档的程度」减去「那篇文档平均有多好被匹配」：

$$B(i) = -\Big(\max_j\cos(t_i,p_j) - \underbrace{\frac{1}{|\mathcal{D}(d_i)|}\sum_{j:\,d(j)=d_i}\max_j\cos(t_j,p_j)}_{d_i = \text{top-1 命中的文档}}\Big)$$

即减去「文档 $d_i$ 被所有工单匹配到的平均分数」这个流行度先验。这是双向（工单侧 + 文档侧）中心化，保留绝对余弦刻度。

**实测结果：**

| 变体 | α | β | γ | γ-X |
|---|---|---|---|---|
| ABS −max（基线） | **0.9680** | **0.8075** | **0.9022** | **0.9135** |
| B 双向中心化 max − prior | 0.8160 | 0.6273 | 0.6422 | 0.7500 |
| B+ 与 top5 形状量组合 | 0.4960 | 0.5031 | 0.3378 | 0.7115 |

**判决：无效，且有害。** B 相对基线在 4 个场景上分别落后 **0.152 / 0.180 / 0.260 / 0.164**。

**为什么失败**：原型 §5.3 已实测，300 篇文档里有 **49 篇属于 22 组重复件、组内相似度 0.982–0.985**，而且 `ref_count` 字段在 24–49 之间波动。**在这个语料上，文档流行度先验几乎全是被重复件污染的伪信号** —— 减去它等于把真正的信号也减了。真实语料上重复件少，先验更干净，**方向 B 在真实企业知识库上仍值得一试，但本实验无法支持这个结论**。

### 方向 C：固定检出比例 vs 逐场景最优阈值 —— ✅ **实测支持，但只在一个窄条件下**

**初稿的怀疑**：§4.3 用「阈值数值的极差」比较 ABS 和 S1/S2，可能不公平。S1/S2 的阈值等价于「固定检出比例」，它的极差大是因为各场景最优比例不同；ABS 的极差小可能只是巧合。**要公平比较，应该比较「跨场景意图级 F1 的稳定性」。**

**实测（`results_directionC.csv`，ABS + 固定检出比例策略）：**

| 策略 | α | β | γ | γ-X | 跨场景 F1 标准差 |
|---|---|---|---|---|---|
| ABS 逐场景最优阈值 | 0.8889 | 0.6250 | 0.8387 | 0.9630 | **0.1286** |
| 固定检出比例 10% | 0.7500 | 0.2500 | 0.2353 | 0.1429 | 0.2744 |
| 固定检出比例 15% | 0.7500 | 0.4444 | 0.4211 | 0.2667 | 0.2023 |
| 固定检出比例 18.55% | 0.8889 | 0.5455 | 0.4211 | 0.2667 | 0.2647 |
| **固定检出比例 25%** | 0.6667 | 0.5000 | 0.5714 | 0.4706 | **0.0873** |
| 固定检出比例 30% | 0.6154 | 0.5714 | 0.7500 | 0.5556 | 0.0883 |

**判决：部分支持，且带一个明确的条件。**

- 最优的固定比例是 **25%**（标准差 0.0873），**确实比逐场景调阈值的 ABS（标准差 0.1286）更稳** —— 稳 32%。所以「自适应阈值确实有价值，只是要按比例汇报」这个判断**成立**。
- **但代价很大**：固定 25% 的平均 F1 只有 0.5523，而 ABS 逐场景最优平均 0.8289 —— **为了让波动小 32%，牺牲了 33% 的平均性能**。
- 且最优点很不锐利：25% 和 30% 的标准差几乎一样（0.0873 vs 0.0883），而 10%/15%/18.55% 明显更差（0.20–0.27）。**这个「最优点」更像是平台区而非峰顶，可信度有限。**

**能下的结论只有一条**：在「无法为目标语料标注 ground truth、无法逐场景调阈值」的**冷启动**约束下，「固定检出 25%」是一个比「猜一个绝对余弦阈值」更稳的退化策略。**一旦能为目标语料标少量样本（哪怕 20–30 个意图），逐场景调阈值就完胜。**

| 方向 | 实测判决 | 是否值得继续 |
|---|---|---|
| A 形状量 | ❌ AUC 0.096–0.317，比随机还差 | **否**，机理已定位（形状测的是检索独特性，不是覆盖） |
| B 双向中心化 | ❌ 落后基线 0.15–0.26 | **仅在真实语料**（本语料 49/300 篇是重复件，污染了先验） |
| C 固定检出比例 | ✅ 稳 32%，但平均 F1 掉 33% | **有条件**，仅冷启动场景 |

**如果一定要继续做这个课题，我建议把论文的算法贡献从「打分函数」挪到「阈值选取协议」** —— 因为本次实测已经把结论逼到了一个很硬的位置：

> 意图级 AUC 0.968 的段落级 max-cosine 已经很强；S1/S2 数学上动不了它，S3/S4/S5 在真实语料上系统性反噬。**真正没有解决、且有明确改进空间的问题，是「目标语料没有 ground truth 时，阈值从哪来」。**

具体到公式，可以设计一个**少样本阈值标定协议**：

$$\hat{	au} = \arg\max_{\tau} \; \frac{1}{B}\sum_{b=1}^{B} \Big[ \text{F1}@\tau \;\text{on bootstrap sample } b \Big] \; +\; \lambda \cdot \text{Pen}(\tau)$$

在目标语料上做 B 次 bootstrap，用「阈值在最坏分位数上的表现」而不是「在均值上的表现」来选阈值（对分布漂移鲁棒），并对过度激进的阈值加惩罚。**这个问题不需要新数据，只需要换评价协议**，而且 §4.3 / 方向 C 的实测数据已经为它提供了动机。

## 10. 给论文第 5 章的建议（因为「这条路走不通」，所以换个立题角度）

既然标准化路线已被实测否掉，论文的算法贡献不应该写成「我们提出了一个更好的标准化打分」，而应该写成**一篇诚实的负结果 + 一个可复现的评价协议**。建议的第 5 章结构：

**5.1 阈值不可迁移性的形式化刻画**
- 命题 1：设 $g:\mathbb{R}	o\mathbb{R}$ 严格单调增，则 $\mathrm{AUC}(g(c)) \equiv \mathrm{AUC}(c)$。（用 §1 的 ρ 表 + Mann-Whitney U 的定义给出 3 行证明）
- 推论：任何「换刻度」类方案（分位数、z-score、min-max、winsorize）在任何数据集上都无法提升任何排序类指标。
- **这一节本身就是贡献** —— 它把大量文献里「我们用 z-score 归一化所以更鲁棒」的说法一刀切掉。

**5.2 反例：分组标准化为什么在真实数据上失效**
- 用 §3（S3 α=1.0000）与 §6.5（S3 banking77=0.4344）的对照。
- 机理：组内标准化对「整组同质劣化」的缺口意图具有结构性盲区（§5 消融的 S4b=0.7520 是同一现象的极端形式）。
- 一句话结论：**分组标准化只能消除「组间偏移」，不能识别「组内整体缺失」—— 而知识缺口恰恰常常就是组内整体缺失。**

**5.3 阈值可迁移性的真实边界**
- §4.3：同一模型同语言内，ABS 阈值极差 0.0264，其实很稳。
- §6.7：跨语言（换模型）时，阈值把 77/77 全判为缺口。
- **论断**：绝对阈值锚定的是「模型 × 语言」的刻度。刻度不变则稳，刻度变则崩。这比「绝对阈值不可用」精确得多，也更有工程价值 —— 它直接给出了使用边界。

**5.4 可迁移性指标的度量陷阱**（§8 方向 A 的负结果）
- 方向 A 的阈值极差 0.0018（AUC 0.112），ABS 的极差 0.0264（AUC 0.968）。
- **论断**：跨场景阈值极差可以单独优化成假象。任何声称「可迁移」的方案必须同时报告跨场景 AUC/F1。
