# PoC 产物索引

本文件逐个登记 `poc/kbgovernance/` 下每个产物文件：**它回答什么问题、支撑论文哪个数字或结论、
进论文还是仅备查、被谁引用**。所有条目都来自实读该文件的表头与数据行，不是按文件名推断。

统计口径（已用脚本双向核对，磁盘集合与索引集合完全相等）：

- `standardize/` 目录下**文件总数 N₁ = 29**（顶层 25 个 + `data/` 2 个 + `__pycache__/` 2 个），本文档对应条目 **29**。
- 上层 `poc/kbgovernance/` 的机读指标产物与门禁报告 13 个，本文另列 13 条。
- 合计 **N = M = 42**，无遗漏、无杜撰条目。

> 核对方式：遍历磁盘得文件集合，从本文件表格首列抽取条目（花括号展开）得索引集合，
> 双向差集均为空集。

三层分类（与 `README.md` §3 一致）：

- **A 机读指标产物** —— 论文数字的唯一合法来源，门禁 `check_numbers.py` 逐个收集其数值叶子。
- **B 备查产物** —— 对应技术方案 E7–E14 那批已完成实测但**不进论文正文**的实验，保留供答辩现场查证，**不得删除**。
- **C 中间产物 / 门禁产物** —— 输入语料、日志、字节码、门禁报告。

### `results_transfer.csv` 专项：它真的没人用吗？

实读结论：**整表 32 行 × 10 列，没有任何一行数值被三份受审文档引用。** 验证方式：

1. 逐列比对。列 `方法, 源场景, 源阈值, 目标场景, 迁移后F1, 迁移后P, 迁移后R, 检出意图数, 目标场景最优F1, AUC衰减`。
2. 抽该表独有值在三份受审文档中检索：`0.8444`（ABS→γ-X）、`0.4545`、`0.7619`、`0.7273`、`0.8485`（A4→γ）、
   `0.8385`、`0.8910`（S6 源阈值）——**全部 0 命中**。
3. `AUC衰减` 列的独有值 `0.1605 / 0.3067 / 0.3558 / 0.2115 / 0.1689` —— **全部 0 命中**。
4. 逐个文档 grep `results_transfer`：
   - 技术方案 §6.3 E10 行：**只写文件名** `results_transfer.csv`，同行引用的数字是 `0.9538 / 0.7925`（属 E11）。
   - 本科版实施方案 §4 的 E7 行与 E10 行：**都只写文件名**，判语分别是「数据保留在 `standardize/results_transfer.csv`，论文不引用」和「`standardize/results_transfer.csv` 保留」。
   - 本科版实施方案 §3 风险表虽然把 `standardize/results_transfer.csv` 列为**出处**，但那一行断言的数字是「跨场景阈值极差仅 0.0264」——该数字的真实机读出处是 `derived_metrics.csv:threshold.abs_5scenario_range`，其 `source_files` 列写的是 `standardize/results_auc.csv`。**列错出处，不是本表提供。**
   - 唯一真正使用本表数据的是 `STANDARDIZE_RESULT.md` §4.4 与表 4-2（该文件是探索期报告，不在门禁扫描的三份文档内）。

**处置：保留，不删。** 它是 E7 / E10 这条已砍立论的原始证据，且 E7 在技术方案 §6.3 的声明指标
（召回率 / 召回方差）与本表实际列（迁移后 R / 迁移后 F1 / AUC 衰减）并不完全对应，
删掉后这条实验就再无任何可复核的落盘数据。

1. **E7 声称的因变量「召回方差」没有任何产物承载。** 全目录检索 `召回方差` / `方差`：
   技术方案只在 §6.3 的 E7 行出现过一次，本科版实施方案 E7 行复述一次，产物侧零命中；
   `derived_metrics.csv` 的 52 行里只有 `directionC.*_sd_f1_*`（F1 标准差），无任何召回方差派生行。
2. **E12 的「对照组：域内 (0.968 / 0.4344)」标注口径不当。** `ablation.csv` 内**不含 0.4344**
   （该值是 `results_banking77_en.csv` 全量 / S3 领域内z 的 AUC）；而 0.968 在 `ablation.csv` 里
   对应的是「S4 去掉域内（仅全局）」与「ABS 绝对余弦（基线）」，不是「域内」本身
   （域内分位数 S3 的 α AUC 是 0.992）。数字溯源审计.md §6.3 E12 行已标注「同值（口径标注不当）」。
   这不是新增问题，但 E8–E14 表把 `ablation.csv` 列为唯一数据文件、又在同一行给出跨文件数字，属标注不严谨。
